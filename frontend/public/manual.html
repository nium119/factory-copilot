Agent 平台操作手册

本体驱动的动态 Agent 平台。换一份行业本体，自动生成对应的业务域、操作和推理链，Agent 能力随本体变化实时更新，无需手动编码。

产品概述

平台分为三个区域：

  • 左侧业务域列表：显示当前本体编译生成的业务域，点击即可开始对话
  • 中间对话区：自然语言提问，系统自动识别意图并查询数据
  • 系统配置（底部"配置"入口）：管理业务域、API 接口、链条、日志等

顶部本体图谱下拉框切换不同行业本体。右侧"配置"面板中可查看完整操作手册。

术语说明
本体用 OntoStudio 建模的行业知识图谱（概念、属性、关系、规则）
业务域一组业务概念的集合，如"生产管理"包含工单、工序、物料等
操作单个概念的查询或动作能力，如"工单查询"
链条多概念顺序推理路径，如"设备故障→安灯→工单→物料"
数据源概念的数据来源：业务系统实时接口 或 图数据库

使用流程

  1. 在 OntoStudio 中打开本体文件，推送到 Neo4j
  2. 回到本平台，顶部切换对应本体图谱
  3. 点击底部「配置」→「业务域配置」
  4. 点击「规则推导」或「AI推导」自动生成业务域
  5. 点击「应用」编译——左侧业务域列表出现入口
  6. 点击左侧业务域，输入问题开始对话

业务域配置

自动生成

  • 规则推导 基于本体概念层级自动分组，速度快、结果确定
  • ⭐ AI推导 大模型根据语义和关系智能分组，右侧抽屉实时展示思考过程（推荐）
推导只生成域配置，不会立即生效。点「应用」后才编译并显示到左侧列表。

手动调整

  • 添加业务域：新建域，可编辑名称、图标、描述
  • 概念分配：从下拉列表选择概念拖入域卡片
  • 删除域：卡片右上角删除按钮，点「应用」后生效
  • 域排序：拖拽卡片调整顺序

状态管理

  • ✓ 已应用 当前配置已编译生效，可点「撤销」回退
  • ● 未应用 配置有改动尚未编译，点「全部应用」生效
  • 清除业务域：清空全部域配置和已编译的 Agent
  • 版本：查看和恢复历史配置版本

API 接口

为概念配置外部 API 数据源，查询时优先从业务系统获取实时数据。

配置

  1. 添加 API → 填写 Base URL、选择认证方式（Bearer / API Key / Basic）
  2. 添加接口 → 选择概念、HTTP 方法、请求路径
  3. 展开接口 → 配置请求参数（映射到接口字段）、响应字段（映射到本体属性）
  4. 配置成功条件（HTTP 状态码 / 业务字段校验）

验证与生效

  • 测试连接：验证 API 地址可达
  • ▶ 测试：调用接口查看返回数据和字段
  • 保存：存储配置到数据库
  • 应用：激活配置，后续查询走 API

降级策略

每个 API 系统可单独控制降级行为：

  • 降级开启 API 调用失败时自动切换图数据库查询
  • 降级关闭 API 失败直接返回错误

操作目录

列出当前本体所有概念的查询和操作能力：

  • 概念名、所属业务域、父级概念
  • 数据来源（业务系统 或 图数据库）
  • 可执行的操作列表
  • 触发词管理——输入关键词可直接匹配到此操作

链条配置

链条定义多概念依次查询的推理路径。每条链包含多个步骤，每步指定查询的概念和处理逻辑。

在 系统配置 → 链条配置 中创建、编辑、启用/禁用链条。

本体切换

顶部「本体图谱」下拉框列出 Neo4j 中所有已推送的行业本体。切换时：

  1. 系统自动加载新本体的概念数据
  2. 左侧业务域列表和系统配置页联动刷新
  3. 如新本体无业务域，进入「业务域配置」使用推导生成
  4. 切换不影响其他本体的配置数据（按 namespace 隔离）
