Agent 操作手册

本体驱动的动态 Agent 平台。换一份行业本体，自动生成对应的业务域、操作和推理链，Agent 能力随本体变化实时更新，无需手动编码。

系统概述

Agent 平台由三部分组成：

  • 侧边栏：点击业务域开始对话
  • 对话区：自然语言查询，Agent 自动路由数据源
  • 系统配置：管理业务域、API 接口、链条、日志

右侧顶部 本体图谱 选择器切换不同行业本体。

核心概念

概念说明
业务域一组业务概念的集合，如"生产管理"包含工单、工序、物料等
操作 (Skill)单个概念的查询/操作能力，如"工单查询"
链条 (Chain)多概念顺序推理路径，如"设备故障→安灯→工单→物料"
Agent业务域的对话入口，持有若干 Skill 和 Chain
数据源概念的数据来源：业务系统(API) 或 图数据库(Neo4j)

快速入门

  1. 在 OntoStudio 中建模本体 → 推送到 Neo4j
  2. 切换本体图谱选择对应行业
  3. 业务域配置 → 点击「规则推导」或「AI推导」自动生成域
  4. 调整域配置 → 点击「应用」编译生效
  5. 左侧点击业务域，开始对话

业务域配置

生成业务域

  • 规则推导 基于概念父子层级自动分组，速度快
  • AI推导 大模型根据语义和关系智能分组，更贴合业务

手动管理

  • 添加业务域：创建新域，编辑名称、图标、描述
  • 分配概念：从下拉列表选择概念拖入域卡片
  • 保存：将修改写入数据库
  • 全部应用：编译生效，生成 Agent 到侧边栏
  • 撤销：已应用状态下可撤销，禁用 Agent 回到未应用
推导只生成域配置，不会自动创建 Agent。需要点「应用」才编译。

API 接口

为概念配置外部 API 数据源，查询时优先走业务系统而非 Neo4j。

配置步骤

  1. 添加 API 系统 → 填写 Base URL 和认证信息
  2. 添加接口 → 选择概念、方法、路径
  3. 展开接口 → 配置请求参数映射、响应字段映射、成功条件
  4. 测试连接 验证连通性
  5. 保存 → 应用 激活配置

降级控制

每个 API 系统可配置「降级到图数据库」开关：

  • 开启 API 不可用时自动切换到 Neo4j 查询
  • 关闭 API 失败直接报错，不降级

操作目录

查看所有概念的查询/操作能力，包括：

  • 所属业务域和父级概念
  • 数据来源（业务系统 / 图数据库）
  • 可用操作和触发词

可在 系统配置 → 操作目录 中管理触发词。

链条配置

链条定义了多概念顺序推理路径。例如：

设备故障 → 安灯事件 → 受影响工单 → 物料库存

在 系统配置 → 链条配置 中创建和编辑。

API 日志

每次 API 调用自动记录到数据库，在 系统配置 → API 日志 查看：

  • 时间、用户、会话、消息
  • 概念、方法、URL、状态码、耗时
  • 点击行展开查看完整请求体和响应体

本体切换

顶部「本体图谱」下拉选择不同行业本体，切换后：

  1. 侧边栏和系统配置自动联动刷新
  2. 如新本体无业务域配置，进入「业务域配置」点击推导
  3. 推导 → 应用 → Agent 即可使用
