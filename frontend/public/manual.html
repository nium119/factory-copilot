Agent 平台操作手册

本体驱动的动态 Agent 平台。换一份行业本体，自动生成对应的业务域、操作和推理链，Agent 能力随本体变化实时更新，无需手动编码。

产品概述

术语说明
本体用 OntoStudio 建模的行业知识图谱（概念、属性、关系、规则）
业务域一组业务概念的集合，如"生产管理"包含工单、工序、物料等
操作单个概念的查询或动作能力，如"工单查询"
链条多概念顺序推理路径，如"设备故障→安灯→工单→物料"
数据源概念的数据来源：业务系统实时接口 或 图数据库

界面布局

平台采用左侧菜单 + 内容区的布局：

菜单项功能
AI助手主对话界面，左侧 Agent 列表 + 右侧对话区。点击 Agent 开始对话
待审批审批管理中心，分离「待审批」和「已处理」两个 Tab。支持通过/拒绝操作，实时推送更新
业务域配置系统配置入口：业务域、链条、技能、API接口、MCP服务、A2A代理、KPI、告警规则、资源状态
对话视图内的 Agent 侧边栏保留「新建对话」和「历史记录」按钮。菜单可折叠为图标（点击顶部logo），节省空间。

对话与确认

对话流程

  1. 左侧菜单点击 AI助手，选择业务域 Agent
  2. 输入自然语言问题，系统自动识别意图并路由到对应操作
  3. 点击消息可展开思考链，查看路由分析→意图识别→参数提取等执行步骤

操作确认

具有 requiresConfirmation 标记的写操作会弹出确认表单：

  1. 用户填写/修正参数（支持服务端搜索物料、工艺路线等跨概念数据）
  2. 点击确认提交
  3. 用户角色符合 authorized_roles → 直接执行
  4. 用户角色不符 → 委托审批，进入待审批队列
确认表单不限时，参数支持必填校验。服务端搜索字段（如物料编码）输入触发实时搜索，选中后提交。

审批流程

流程

  1. 用户发起写操作 → 确认表单 → 角色不符 → 委托审批
  2. 消息提示"已确认操作并提交 XX 审批"，思考链显示完整链路
  3. 有权限的审批人在 待审批 菜单看到待办卡片
  4. 点击通过 → 自动执行原始操作 → 结果写入思考链
  5. 点击拒绝 → 填写原因 → 思考链标红

实时通知

  • 新待审批 → 浏览器通知 + 右下角悬浮红点 + 菜单角标
  • 审批完成 → 对话消息实时刷新（SSE推送，无需手动刷新页面）
  • 待审批/已处理列表实时更新

已处理

审批通过/拒绝的记录进入「已处理」Tab，显示审批人、时间、参数详情。通过卡片绿标，拒绝卡片红标。

业务域配置

菜单 业务域配置 → 默认 Tab「业务域」。

自动生成

  • 规则推导 基于本体概念层级自动分组，速度快、结果确定
  • ⭐ AI推导 大模型根据语义和关系智能分组，右侧抽屉实时展示思考过程（推荐）
推导只生成域配置，不会立即生效。点「应用」后才编译并显示到 Agent 列表。

手动调整

  • 添加业务域：新建域，可编辑名称、图标、描述
  • 概念分配：从下拉列表选择概念拖入域卡片
  • 删除域：卡片右上角删除按钮，点「应用」后生效
  • 域排序：拖拽卡片调整顺序

状态管理

  • ✓ 已应用 当前配置已编译生效，可点「撤销」回退
  • ● 未应用 配置有改动尚未编译，点「全部应用」生效
  • 版本：查看和恢复历史配置版本

API 接口

为概念配置外部 API 数据源，有 API 配置时优先从业务系统获取实时数据。

配置

  1. 添加 API → 填写 Base URL、选择认证方式（Bearer / API Key / Basic）
  2. 添加接口 → 选择概念、HTTP 方法、请求路径
  3. 展开接口 → 配置请求参数和响应字段映射

请求参数

字段说明
来源用户 Agent 从对话提取 / 系统 环境变量 / 会话 JWT Token
属性名用户参数从本体属性下拉选择，系统/会话参数自由输入
映射到对应的 MES API 请求字段名
默认值系统参数填环境变量名，会话参数填 JWT claim 名
必填Agent 提取不到时要求用户补充
无 API 配置的概念走 Neo4j 图数据库查询。有配置的概念直接走 API，不降级。

操作目录

列出当前本体所有概念的查询和操作能力。启动时自动编译，无需手动触发。

列说明
概念本体中定义的概念，显示中文标签和父级概念
数据源API 已配置接口 / Neo4j 图数据库
业务域所属域，编译时自动分配
触发词用户输入匹配到这些关键词时直接触发对应操作

链条配置

链条定义多概念依次查询的推理路径。在 业务域配置 → 链条编排 中管理。

本体切换

业务域配置页顶部「本体图谱」下拉框列出 Neo4j 中所有已推送的行业本体。切换时：

  1. 系统自动加载新本体的概念数据
  2. Agent 列表和系统配置页联动刷新
  3. 启动时自动编译，已有的域配置无需手动操作
  4. 如新本体无业务域，使用规则推导或 AI 推导生成
  5. 切换不影响其他本体的配置数据（按 namespace 隔离）
